BeatCraft - pattern-based beat making

Start: double-click BeatCraft (BeatCraft.exe on Windows, BeatCraft.app on Mac,
or on Linux run the .AppImage, or ./install.sh from the tar.gz and pick BeatCraft from the app menu).

Keys
  Space            play / pause
  L                pattern / song mode
  F6 F7 F8 F9      channel rack, piano roll, browser, mixer
  Z S X D C ...    play the selected channel from the computer keyboard
  - / =            keyboard octave down / up
  Ctrl/Cmd + S     save

Projects and exported WAV files are saved in your Music folder, under "BeatCraft".

First start on Mac: if macOS says the app can't be checked, right-click BeatCraft.app
and choose Open (the app is not notarised by Apple).
First start on Windows: if SmartScreen warns, choose "More info" > "Run anyway".
